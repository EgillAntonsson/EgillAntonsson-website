This is a CLAP-plugin implementation of the same intentionally unhelpful idea as my Shipment Evaluator JSFX.

How the evaluation works

Add the plugin to a track and start playback. Its amp-style Evaluation Meter climbs toward 11, then displays SHIP IT!. The result stays visible while playback continues; stopping or pausing resets the meter for the next evaluation. The result text cycles through seven rainbow colors, changing once per second.

Audio behavior

The verdict is always the same: the plugin does not judge whether a project is ready. It does not analyze or alter the audio; its stereo audio ports pass the input through unchanged.

Build and install

The plugin's source code and build and installation instructions are on GitHub. The current instructions describe building a macOS .clap bundle.
